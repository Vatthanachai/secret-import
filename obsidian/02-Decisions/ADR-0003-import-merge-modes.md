# ADR-0003: โหมดการ merge และ backup

## Decision
| โหมด | ผลกับ key ที่ซ้ำ | ผลกับ key เดิมที่ไม่อยู่ในไฟล์ import |
|---|---|---|
| `overwrite` (ค่าเริ่มต้น) | ใช้ค่าใหม่ | เก็บไว้ |
| `skip` | เก็บค่าเดิม | เก็บไว้ |
| `replace` | ใช้ค่าใหม่ | **ลบ** |

- ก่อนเขียนทุกครั้ง สร้าง diff ที่ระบุแต่ละ key ว่าเป็น `Added` / `Changed` / `Unchanged` / `Removed` (`Removed` มีเฉพาะโหมด replace) / `Skipped` (เฉพาะโหมด skip)
- ค่า secret ซ่อนเป็น `••••` จนกว่าผู้ใช้จะกดดู ใน CLI ต้องใส่ `--show-values` ถึงจะเห็น
- ไม่มีการเปลี่ยนแปลงเลย (ทุก key เป็น Unchanged หรือ Skipped) → ไม่ต้องเขียนไฟล์
- มี `--dry-run` ให้ดู diff โดยไม่เขียนจริง
- สร้าง `secrets.json.bak` ทุกครั้งก่อนเขียน เก็บแค่ไฟล์ล่าสุดไฟล์เดียว

## Rejected
- เลือก merge ทีละ key (ติ๊กในตาราง) เกินความจำเป็นในเวอร์ชันแรก
